## Automated Dashboard and Report Project Documentation

## Project Objective:
Demonstrate data cleaning and analysis skills through an automated data-processing project using a synthetically generated dataset with injected errors resulting in a dashboard that presents answers to key questions and metrics.

## Output:
Documentation, script, and spreadsheet for a portfolio piece explaining the process used for data handling and analysis.

## In Scope:

Python script that generates raw data with randomly injected errors.

Python script that cleans and processes the raw data, applies formatting, and uploads the results to Sheets.

Documentation with a set of questions to guide data analysis and generate insights.

Calculations sheet that processes the data and prepares the results for presentation.

Dashboard that answers the questions and presents the key metrics and insights in an easy-to-understand format.

## Out of Scope:

The project only covers a period of 6 months (January 2026 - June 2026).

This is a portfolio project and has not been used in a company's operational environment.

The data is synthetic and is not connected to real client records or live operational databases.

The workflow is executed manually and does not include scheduled automation.

## Milestones:

**Week 1**

Define the data structure and fields to be generated.

Develop a Python script that generates 1,000 raw records with intentionally injected errors, duplicates, and disordered IDs.

Create a document with SMART questions to guide data analysis.

Verify that duplicate records are generated as expected.

Verify that records are not consistently ordered by ID.

Verify that some values contain incorrect or inconsistent formatting.

**Week 2**

Develop a Python script that cleans and formats the raw data and uploads the results to Google Sheets.

Verify that the script cleans and formats the data correctly.

Verify that the data is uploaded to Google Sheets without errors.

**Week 3**

Build the calculations sheet to process the cleaned data and answer each analysis question.

Determine which charts best communicate the answers to each question.

**Week 4**

Build the dashboard using the calculated results.

Upload the scripts, documentation, and relevant project files to GitHub.

## Definition of Done:
The generated data is correctly cleaned, formatted, uploaded to the sheet, and accurately displayed on the dashboard. The process is documented, along with the scripts and the Google Sheets document, on GitHub.

## Stack:
Python | Pandas | Sheets | Google Sheets API
